## O que eu faço

- **Site para o seu negócio:** bonito, rápido no celular e fácil de usar.
- **Agendamento e pedidos online:** o cliente marca ou pede sem fila e sem complicação.
- **Bots de atendimento:** respondem as dúvidas dos seus clientes a qualquer hora.

## Como funciona

1. Você conta o que precisa.
2. Eu desenho, construo e reviso cada página.
3. Você recebe um site pronto para vender.
